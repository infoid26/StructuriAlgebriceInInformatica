# Cont Microsoft și progres

Progresul se salvează automat în browser. Conectarea cu Microsoft, atunci când este disponibilă, permite sincronizarea între dispozitive și browsere.

Sunt acceptate conturile universitare cu domeniul `s.unibuc.ro` sau `unibuc.ro`.

La prima conectare, progresul din browser este asociat contului. Fiecare cont își păstrează propriul progres.

Dacă legătura se întrerupe, modificările rămân salvate pe dispozitiv, iar sincronizarea reîncearcă automat. Dacă același răspuns este modificat diferit pe două dispozitive, aplicația permite descărcarea copiei locale înainte de încărcarea variantei din cont.

Deconectarea oprește sincronizarea cu contul pe dispozitivul respectiv.
